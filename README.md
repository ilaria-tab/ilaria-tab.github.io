# Personal webpage

Static GitHub Pages site for the personal webpage of [`ilaria-tab`](https://github.com/ilaria-tab).

The workshop page is available under `/events/`.

## Publish

Create a GitHub repository named:

```text
ilaria-tab.github.io
```

Then push this folder to that repository. The site will be available at:

```text
https://ilaria-tab.github.io/
```
